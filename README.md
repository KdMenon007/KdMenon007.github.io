# KDM SECOPS GitHub Pages Portfolio

Static website files updated to follow the supplied Framer `App.jsx` direction and content.

- `index.html` — profile, experience, home lab, featured projects, in-development and planned work, security feed, analyst brief, toolkit, skills, lifecycle, credentials, research, digital portfolio links and contact.
- `style.css` — responsive dark SOC theme, cyan/green accent palette, animated elements and colorful rectangular link cards.
- `script.js` — mobile navigation, terminal simulation, scroll reveal and publisher RSS feed integration.

## Publish
Replace all three files in `KdMenon007/kdmenon007.github.io` and commit to the branch used by GitHub Pages. Wait for the Pages deployment, then hard-refresh with `Ctrl+Shift+R` or test in a private window. CSS/JS references include `?v=20261018-2` to help bypass stale browser caches; increment this value on future edits.

## Notes
The RSS feed depends on the third-party RSS2JSON proxy and may be temporarily unavailable. The Radware map is an external embedded service. Terminal/radar-style displays are illustrative, not live SOC telemetry. Current TryHackMe/Hack The Box values should be checked on the linked profiles. Planned/in-development work is explicitly labelled.
