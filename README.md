# Kiran Menon — Cybersecurity Portfolio

A responsive cybersecurity portfolio rebuilt from the supplied Canva portfolio.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Inter + JetBrains Mono)

## Run locally

```bash
cd kiran-cyber-portfolio-v2
python3 -m http.server 8000
```

Open:

http://localhost:8000

## GitHub Pages

1. Create a repository, for example `portfolio`.
2. Copy all files into the repository.
3. Commit and push.
4. GitHub → Settings → Pages.
5. Select **Deploy from a branch**.
6. Select `main` and `/root`.
7. Save.

## Important
The LinkedIn URL is intentionally generic because the supplied Canva content did not provide a specific LinkedIn profile URL. Replace it in `index.html` when you have the exact profile URL.

The site uses the information supplied in the Canva portfolio and does not invent certification URLs or certificate details.
